# 大秘

市委书记的秘书，六十个月。单文件 HTML，双击就能玩，存档在浏览器本地。

江东省云州市，下辖三区三县。你二十九岁，市委办综合科副科长，被新到任的市委书记点名当秘书。
每月三件自己的事、两件呈书记的事。调研、考察、回访与案头待办共用这三次行动。
城关旧改、青川旧账和干部到任都有跨月后续：先核实，下个月定办理意见，再过一个月核验结果。期限到了还没办，会留下记录和后果。
旧改的补款、逐户复核和催进度，会影响后来的信访反扑和工地问责。干部到任要看现场缺的是钱、人还是手续；核验没通过，可以保留材料补办一次。办事可靠的人能承担日常落实，不必总靠回访维持。

书记的性格开局随机，你看不见，只能从他的批示里猜。
「干净」和「线索」这两个数你也看不见，只能从纪委的待办和别人看你的眼神里感觉。
灰色选项会留下隐患，部分代价在后面才出现。伸过的手不会因为自查被抹掉。

结局跨局记在图鉴里。

学校布局、环保整改和河流治理可以根据打听来的顾虑修订方案，失利后各有一次有限再议。干部的擅长与短处通过实际考察显现；退件可以按真实缺项补证，市长会回应公开布局，后半任也会遇到不同的执行、积案或交接难题。

## 改

`index.html` 是拼出来的成品，**不要手改**。源码在 `src/`：

```
src/css/main.css
src/js/*.js        引擎：队列、卷宗、常委会、纪律、链条、结局
src/data/*.js      内容：事件、主线、议题、干部池、模板、结局正文
build.py           把 src/ 拼成 index.html，零依赖
test/sim.js        无头跑局
```

改完跑：

```bash
python3 build.py        # 重新拼 index.html
node test/continuity.js # 跨月、暗线、人物记事与存档回归
node test/decisions.js  # 修订、有限再议、适岗与 v2.4/v2.6 旧档
node test/strategy.js   # 退件补证、公开布局应对、后半程支线
node test/decisions-sim.js # 200 局实际使用前三项玩法
node test/strategy-sim.js # 200 局使用全部六项玩法
node test/story-audit.js # 议题口风、条件剧情、结局和缺陷回归
node test/ops-sim.js     # 部门参与的完整局与逐月岗位一致性
node test/delivery.js   # 办理方式、长期后果、干部实绩与旧档兼容
node test/continuity-sim.js # 120 局实际办理待办的模拟
node test/sim.js 200    # 四种打法各 200 局，看结局分布和报错
```

`test/sim.js` 跑四种自动策略，报告结局、平均月份和运行报错；不等同于真人平衡验收。
`test/continuity.js` 检查跨月状态、资源消耗、不同办理后果、人物记事、暗线前置和存档随机序列。
`test/continuity-sim.js` 在原策略中加入待办办理，检查完整局能否结束以及资源、待办状态是否合法。

内容在 `src/data/*.js`，按文件名排序装配；持续待办逻辑在 `src/js/55-work.js`。
新存档和导出存档记录随机数状态。旧存档可以继续，首次载入沿用旧版按种子和月份恢复随机数的办法；过去已经结束的表决不会补造待办。
