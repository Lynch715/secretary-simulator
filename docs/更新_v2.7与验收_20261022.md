# v2.7：六项可玩性深化与存档保护

## 玩法

1. **具体修订方案。** 学校布局、环保整改、河流治理各有两份修订。先打听相关常委的口风，再使用一件自己的行动拟办。修改有不同经费、立场、近期收益和执行后续；一般立场不因此改变。一份议题只能选择一项修改，保留原方案也可以，不额外收费。送出并不等于获批。
2. **失利后有限再议。** 上述三个新启用的议题首次失利后，可在期限内各争取一次：补齐材料保留完整范围，或支出一份盘子只报局部试点，也可以归档不再报。首轮票数、结果及损失保留；再议另记结果，仍可能失败。会期避开常规议题和主要表决，党校顺延，任期结束不安排未来会议。试点不享有完整方案的收益或落地叙述。
3. **干部适岗。** 八名干部各有擅长与短处，考察、调研或到任回访逐步揭示。新任命核实后，适岗干部可按专长分工；工作碰上短处时，需要互补骨干。协办占两件行动；经费、廉洁及真实立场问题不能靠专长跳过。适岗与需要长期配合的干部，其后续日常报送间隔不同；旧干部已有的验证待遇不追改。
4. **可回应的退件。** 对新发生的提名、谈话、汇报退件，按书记性格及真实缺项给理由。补证走原有考察、打听或实际办结材料，每件退件本月最多补一次，仍消耗自己的行动。精明型书记要求的是本次人选、本次岗位的口风，不能拿另一职位的询问充数。补齐缺项提高再次呈报机会，但不保证批准；原退件不撤销，再报仍占呈报机会，能力不足也不能靠补纸面材料变强。
5. **回应公开布局。** 新应对只记录公开任命、实际通过的议题和落实的补偿，不读取未公开提名、私下打听或隐性污点来决定新策略。连续任命会引来人事支持上的争取；项目落地会引来年度经费先后次序上的应对。经费动作先报明确月份，之后才可能调整一份机动盘子；财政或已批准的向省里说明能保护该份额。既有市长计划不会半途换目标。
6. **后半任不同难题。** 第三十个月起，在没有关键主线剧情占用的主场景中，根据实际状态择一进入两幕支线：未结事项、可靠干部交接、推进后的执行验收。每局至多一条，至少三个月后再接后幕，关键主线优先，所以正文显示实际间隔月数。办理与交接选择有实际行动、经费或后续影响；已离任干部不会被当作仍在原岗，后来补办的结果也不改写成早已办成。
