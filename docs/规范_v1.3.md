## 二、数值

### 顶部指标条（v1.3 砍到 4 格）

六格里混了两样不属于你的东西，玩家一眼看不明白——「威信」是书记的，不是秘书的；「干净」是你心里的数，摆在条上就成了刷分。现在条上只放你自己的四样：

| 指标 | 含义 | 太低会怎样 |
|---|---|---|
| **信任** | 书记对你 | <30 进入「换秘书」倒计时 |
| **官声** | 外面怎么说你——其他领导、区县、机关里的人 | 低了外放时没人接，书记走后被清算 |
| **人脉** | 能打出去的电话 | 门槛选项要它（「给信访局老陈打个电话」），用一次少一点 |
| **精力** | 月末安排决定回多少 | 低了每件事多耗半天 |

挪走的两样：

- **威信**（书记在班子里说话管不管用）挪到**班子页周维安那张卡**上，写成一句话加一条细线：「在班子里说话的分量：要看是什么事」。它照样管常委会票数，只是不再冒充你的属性。
- **干净**（你自己的账，从 100 往下掉）**藏起来**，跟「线索」一样玩家全程看不见。只在**结局页**摊开，而且不给数字，给一句话：「有些事你自己记得，别人不一定知道」。

**人脉要真的有用**。至少三成的事件里放一条 `req:{gx:N}` 的门槛选项——一个电话就能办完的那种路子。够不着的时候选项灰着，底下那行换成写好的一句：「统计局管这摊的人，你一个也叫不动」，不写「需要人脉 45」。用了就扣人脉：人情是消耗品。

## 三、每月怎么玩

一回合一个月，一个月 **20 个工作日**，但这 20 天里先被例行的事占掉 **8~13 天**——随书记去省里、陪同检查、会议记录、值班、接待上面来的人、会签、书记的行程和电话，每月随机抽三四项。剩下的 **7~12 天**才是你能自己支配的。界面在指标条下面用一行小字列出这个月被占掉的是什么。

这条是真实的：秘书的时间本来就不归自己。它同时给后面的「随行」「书记临时叫你」留了口子。

玩家每个月只做一件事：处理待办队列。

```
月初简报 → 待办队列 → 点开一件 → （卷宗：先看材料）→ 选拟办意见 → 看结果和留痕
        → 天数用完或事情办完 → 月末安排 → 书记批示 → 结算 → 下月
```

### 三之一、待办队列（v1.2 改）

队列按期限排，不按来源排。每件左边一个标签，写清剩余时间：

| 标签 | 意思 | 颜色 |
|---|---|---|
| **逾期** | 上月顺延过来的，这个月不办就按「不办的后果」结算 | 红条 |
| **本月** | 月底到期 | 墨色 |
| **下月** | 可以放一个月，放了会变 | 灰 |
| **已排期** | 主线下一幕的预告，写着「约 3 个月后」，点开只能看简介 | 淡灰 |

每件还标：来源（书记交办 / 办文 / 有人找你 / 突发 / 主线 / 家里 / 常委会）、规格（便签 / 卷宗 / 链条）、最短耗时。

每月 4~6 件，其中卷宗同时最多 2 件、链条同时最多 1 条。天数总是不够办完全部，玩家每月得放下一两件。

**写事件时按这个耗时来**：单件平均 3~5 天（便签 1~3 天，卷宗连材料 5~8 天，链条一幕 2~4 天）。20 天配 4~6 件，正好办不完。S1 的样本事件耗时是 0.5~2 天，跑无头局 60 个月全办完了，正式事件不能这么写。

**灰色选项的密度**：不要每件事都给一条灰的。正式 80 件里带 `rule` 的控制在三成左右，否则随手点也能把线索堆到 85——S1 样本 12 件里有 11 件带灰，无头局 100% 打出「你自己出事」，那是样本的毛病，不是数值的。

### 三之二、三种规格（v1.2 新）

**便签**：一步办完。点开就是一段话加两三个选项，每个选项标耗时（0.5~2 天）。v1.1 里的大部分单发事件是这种。

**卷宗**（只用在六条主线的部分幕、常委会、匿名信、谈话材料、人事窗口的名单幕；单发事件不用）：先看材料，再办。点开是一份送阅件，下面挂 2~4 份材料，每份标「看一遍要几天」（0.5~1 天）。没看的材料只显示标题和来源，不显示内容。看完的材料会把内容摊开，并在旁边标出它支持或推翻哪条**认定**。

认定是这件事到底是怎么回事的几种可能，比如「高新区数字对不上」这个卷宗有三条认定：口径不同 / 高新区注水 / 统计局漏报。每条认定要看够几份材料、支持够强才亮起来。拟办意见里有些选项要求某条认定亮着才能选，灰着的写清「还差哪份材料」。

```
┌──────────── 市委办公室 · 送阅件 ── 云委办〔2027〕043号 ┐
│ 本月 · 剩 9 天                                      │
│ 高新区报来的一季度数字对不上                          │
│ 统计局给的是 8.1%，高新区材料里写 11.4%，书记后天要用。 │
│─────────────────────────────────────────────────────│
│ 材料                                                 │
│ ✓ 统计局季报摘要 · 统计局 · 已看                      │
│    ……分行业口径，未含园区外注册企业。→ 支持「口径不同」│
│ ○ 高新区一季度总结 · 高新区管委会 · 半天               │
│ ○ 招商局台账 · 市招商局 · 1 天                        │
│─────────────────────────────────────────────────────│
│ 认定                                                 │
│ ● 口径不同（够了）  ○ 高新区注水（还差 1 份）  ○ 统计局漏报 │

材料不是白看的：看过的材料进档案页的「留存材料」，后面别的事件和主线 F 会检查你手里有没有它。同一份材料在不同卷宗里出现只扣一次天数，第二次点开写的是「看过了」。

**门槛提示写成人话**，不写「需要认定：口径不同」。差材料的时候那一行是「这话现在说不出口，招商局台账你还没看」；材料看完了但撑不住，是「手上这些材料撑不住这个说法」。

认定那一栏的标题不叫「认定」，叫**「这件事到底是怎么回事」**，底下是几条可能：● 亮的，○ 灰的。玩家不需要知道 need 是几。

**链条**：一件事分 3~5 幕，每幕一个便签或卷宗，幕与幕之间隔几个月（`gap`，默认 2）。上一幕你选了哪条，决定下一幕是哪一幕（`next:{0:'b2', 1:'b2alt'}`，`'*'` 兜底）。

**逾期不是断线**。一幕拖过期限，按不办结算，然后跳 `lateNext` 指的那一幕——事情不等你，它自己往下走。没有这条，一个五天的卷宗赶上忙月份就能把整条主线掐死：无头局验证过，加之前 40 局只有 1 局走完三幕，加之后 35 局走完。

链条在「已排期」那一档里显示成「约 3 个月后」，点开只有标题，到月份自动变成本月并置顶。

六条主线全是链条，部分突发也是。样板是**青川的旧账**（`data/arcs_qc.js`，三幕）：家属坐在信访局门口 → 书记让你调当年那份事故报告（卷宗，四份材料，认定是「压过」和「压的时候有人经手」）→ 有人在网上发了帖子。

### 三之二之二、选项怎么写（v1.3 新，最重要的一条）

第一版做出来最大的毛病是**选项没有诱惑**：干净的选项没有代价，灰色的选项在界面上明写「可能的处理：收了礼品礼金 · 责令退缴」，等于贴了张「别选我」。玩家闭着眼睛点第一个就能通关，那就不是这个游戏了。

写每一件事的时候按这三条：

**一、三个选项三种代价，没有一个是对的。** 规矩办的那条要付出具体的东西——慢、得罪一个人、或者你因此不知道某件事；折中的那条拿到一半也留下一半尾巴；伸手的那条当场解决问题。写之前先问自己：如果我是玩家，我有没有一秒钟犹豫过。没有就重写。

**二、灰色选项的好处必须是玩家这个月就想要的东西。** 时间、一个拿不到的数、一个人情、书记面前的一句话、某个区县从此对你开门。代价放到三个月以后，而且是写死的，不是概率。例：纸袋那件事，收下之后是「后天他见书记的时候朝你点了下头，城关区那边的门从今天起对你是开的」，不是「你的干净 -12」。

**三、纪律条目不显示在选项上。** 界面只给一根红边。玩家要自己认出来这是伸手。条目表挪到档案页，想查自己去翻。

配套：`n`（选项说明）只写一句你**看得见**的后果，不写数值、不写道德评价、不替玩家总结。「他脸上挂不住，以后见你会绕着走」可以；「这样做不合规矩」不行。

`nt`（放着不办）每件手写一句，不要程序自动拼。「纸袋在抽屉里放到下个月，赵老板当你收了」——这是一句话，不是一个后果列表。

### 三之三、顺延与不办（v1.2 改）

- 「本月」的事没办，自动顺延为下月的「逾期」，只给这一次。
- 「逾期」的事再没办，直接按 `neglect` 结算，进档案「过」栏。
- 有的事顺延后会**变成另一件事**：「区长托你递材料」拖一个月，变成「区长亲自来了」，耗时和选项都不一样。数据里写 `overdue_to: 'xxx'` 就行。
- 「已排期」的主线幕到期那月自动变成「本月」并置顶。

家里的事不走随机：家庭压力 ≥6 时下月必出一件家庭便签，办了 -4，没办 +3 并顺延。连续两次不办，家庭状态变为「破裂」，月末「陪家里」灰掉，结局履历表多一行。

### 三之四、月末安排与书记批示（v1.2 改）

**月末安排**四选一：按时休息（精力回）/ 陪家里（家庭压力 -2；破裂后不可选）/ 周末加班（多出 4 天，下月精力少，家庭压力 +1）/ 去秘书长那坐坐（秘书长热度 -10，口碑 +1，精力不回）。没办完的事在这里列出来，再确认一次。

**书记批示**（v1.3 改）：批示不再只按四个通用档查表——那样太单薄，六十个月翻来覆去就那几句。改成**挂在选项上**：每个拟办意见自带 `rk` 字段，写这个书记看到你这么办会说什么，按性格分三套（只写有反应的那一两种，其余落回通用档）。

这样批示才有信息量：同一件事你选了不同的做法，他说的不是同一句话；同一个做法碰上不同性格的书记，你听到的也不一样。精明型那句「这个数是谁给的？」比任何数值都更让人后背发凉。

**空字符串是一种批示**——界面显示「（没批，右上角签了个名）」。有些事他不会表态，这本身就是表态。

批示长度：一般十个字以内，要紧的事可以到二十字。可以是问句，可以是反问，可以只有两个字。

通用档（选项没写 `rk` 时兜底）：

| 结果档 | 稳健型 | 强势型 | 精明型 |
|---|---|---|---|
| 办得漂亮 | 「阅。」 | 「好。」 | 「这个数是谁给的？」 |
| 办了但留尾巴 | 「再核一下。」 | 「为什么不早报？」 | 「先放着。」 |
| 用了灰色办法 | （不批） | 「知道了。」 | 「以后这类事口头讲。」 |
| 没办 | 「？」 | 「下月一并交。」 | （不批） |

批示不改数值（数值在选项里已经结了），它只负责让玩家猜书记是谁。前六个月的批示就是性格的全部线索，之后档案页「书记」一栏解锁一句总结。

### 三之五、纪律与监督（v1.2 新）

**纪律条目表**（`data/rules.js`，十来条）。每条：名字、类别、严重度 1~5、是不是红线、可能的处理。灰色选项不再手写 risk，写 `rule:'gift'`，界面自动把「可能的处理」显示出来。

| id | 条目 | 严重度 | 红线 |
|---|---|---|---|
| banquet | 该推的饭局没推 | 2 | 否 |
| gift | 收了礼品礼金 | 3 | 是 |
| leak | 把书记的话、没公开的文件透给别人 | 3 | 是 |
| meddle | 打招呼干预项目、人事 | 4 | 是 |
| false_report | 数字、情况报得不实 | 3 | 否 |
| conceal | 知道书记或区县的事没报 | 2 | 否 |
| suppress | 压信访、压帖子 | 3 | 是 |
| retaliate | 收拾举报的人 | 5 | 是 |
| obstruct | 毁材料、串口供 | 5 | 是 |

**线索阶梯**：线索是暗数值，但每过一个阈值，玩家会看见一件新待办：

| 阶段 | 线索 | 玩家看见什么 |
|---|---|---|
| 日常 | <15 | 没事 |
| 线索登记 | 15 | 政法委书记在走廊拍你肩膀：「小X，最近少去港口区。」（人脉高才有这条提醒） |
| 初步核实 | 35 | 待办：「机关纪委请你去谈一下」 |
| 巡察进驻 | 60 | 待办：「省纪委来人调你三年的行程记录」 |
| 审查调查 | 85 | 待办：「有人在楼下等你」，办完直接结局 |

每次「纪委找你」的待办都有两类选项：

- **配合**：交原始记录 / 请他们明确核查范围 / 主动申报回避。配合减不了线索、删不了暗账，但记进档案「配合」一栏，最后审查结论从轻。
- **对抗**：毁材料、串口供（红条，rule:'obstruct'）。线索 +20 以上，暗账加一条，档案记「对抗审查」，结局里再没有「全身而退」。

**风声会淡**（v1.3 补）：线索每个月自动往下掉一点，手里的暗账越多掉得越慢——基础每月 -1.5，每多一条暗账少掉 0.2，最低 -0.2。干净的人几年不碰，风声就散了；手里压着七八件事的人，掉不动。没有这条，任何一局打到第四五年都会被推到审查阶段，那就不是玩家的选择了。

这不是补救，玩家什么也不用做，也做不了。

**没有补救**：收了就是收了，退不回来。灰色选项当月不惩罚，后果在后面慢慢兑现——这是 v1.3 拍板砍掉「退缴/说明/补程序」之后的样子，一条道走到黑。

**界面不给线索提示**：「线索」这个数玩家永远看不到，只能从政法委书记走廊上那句话、纪委的待办、别人看你的眼神里感觉。干净格子下面不加红点。

### 三之六、常委会（不变，加一句）

它是一件加强版卷宗，三段（2026-09-19 已做）：

**材料**是每个常委的书面态度，一份一天。**没看过的人，票面上是一个问号**——你连他投什么都不知道，底下写着「还有 2 个人的态度你不知道」。

**票面**九个人一行一个：明确赞成 / 大体不反对 / 有保留 / 明确反对。不给数字。每个人的倾向 = 写死的基础值 + 好感修正（(好感-50)/25）+ 你做工作的效果。**底线议题上好感那一项直接不算**——市长在旧改上、副书记和组织部长在人事上，你跟他关系再好也没用。纪委书记的底线是「全部」，他身上永远只有基础值。

**做工作**是一组动作，每个花一到两天，改特定几个人的票：去组织部长办公室坐一坐、把信访那份名单给宣传部长看、请书记亲自找副书记谈一次、拿港口区那件事跟秘书长换（这条挂 `rule`）。做过的灰掉，写「已经去过了」，后面那行换成结果：「他交了，改成完全同意」。

**开会那天**是普通的拟办意见，选完立刻按人头结算，结果写进那件事的留痕：「4 比 5，没过」。链条幕的下一幕按 `next:{pass:'x', fail:'y'}` 分叉。

**频率**（2026-09-20 补）：原来常委会只挂在主线上，一局六十个月才开五次，少得不像话。现在**每季度固定开一次**（每三个月的第二个月），那个季度主线自己有常委会就不另开。一局二十三次左右，两个半月一回。

议题从 **10 个常规议题池**（`data/meetings.js`）里抽：全年预算调整、城区中小学布局、港口区国企改制、开发区扩区、安全生产整治、环保督察整改、机构编制、信访积案、招商引资考核办法、公立医院改革。每个带 `cd`，一局里同一个议题不会连着来。

常规议题分软硬两档：**硬的**（财政盘子、国企改制）基础票就是不够，不跑 37%，跑一半 80%，全跑 97%；**软的**（信访、环保、公立医院）你不管也能过，七成到九成，你的活是把材料弄对、别让它出舆情。主线那五场是真硬仗：**不跑必挂**，跑一半六到十成，全跑必过，而全跑要六到十天，月预算才七到十二天。

**区县一把手不参加表决**。写票面的时候只能写九个常委，区县的诉求要挂到替他们说话的常委身上（城关的事挂市长，高新的事挂副书记），做工作对区县的效果走好感不走票数——这一条踩过坑，第一版把区县书记写进 `lean`，那几行全是空的。

**没表过态的人默认不挡书记的议题**：好感修正按 `(好感-45)/25` 算，好感 45 以上就是正面，弃权和不反对都计入赞成。真实的常委会就是这样，书记的议题多数是过的，难的是那几个真有人挡的。

## 三之七、写稿（便签）

拍板：不做组稿，写稿就是一件普通便签。书记交办的稿子（讲话提纲、汇报材料、述职）点开是一段交代和三到四个选项：

```
书记后天去青川讲话，提纲你弄一版。
  · 照他上个月的调子写 · 1.5 天    稳，不出彩
  · 把高新区那个 11.4% 写进去 · 1 天  好看。数字是高新区给的，你没核过
  · 先去统计局问一下再写 · 2 天    慢，但心里有数
  · 让综合科先起个草 · 0.5 天      科长会记你一笔，稿子有点空
```

判定三条：跟书记性格合不合、跟省里风向合不合、有没有用没核过的数。用了没核过的数当月不出事，写进暗账「稿子里的雷」，两三个月后有概率变成一件突发（「网上有人扒出化工园去年死过人」），谁给的素材谁记恨你——这条留着，只是不再让玩家去挑素材。

写稿类待办一局出现 8~10 件。

## 三之八、人（v1.2 新，大节）

书记的活儿是管人，秘书的活儿是管书记跟人之间那道门。前面几节都是「事」，这一节全是「人」：谁能见书记、话怎么传、谁上谁下、谁跟谁掐、你自己的顶头上司。这些不另开页面，全部还是待办，只是多几种便签和链条。

### 1. 干部池

9 个常委、6 个区县一把手之外，再放 **14 个干部**进池子。他们平时不露面，只在人事、告状、谈话、排人这类待办里出现，被提上来之后才进班子页或区县页。

| 位置 | 人数 | 举例 |
|---|---|---|
| 区县副职 | 4 | 城关区长（想接书记）、青川县长（跟县委书记不对付）、白沙常务副县长（本土老人，等着那个年轻书记走）、港口区常务副区长 |
| 市直部门一把手 | 5 | 发改委主任、住建局长、财政局长、公安局长、国资委主任 |
| 市委办内部 | 3 | 秘书长的秘书、综合科科长（你原来的科长，现在给你当副手）、市委办副主任（跟你平级，资格老） |
| 省里下来的 | 2 | 挂职副市长人选、省委组织部的处长（考察组常客） |

每人字段：岗位、年龄、派系、能力、干净（有没有污点、你知不知道）、跟谁近、野心（想去哪个位置）、对你好感。

**露面才画**：池子里的人平时不在界面上。事件里出现过一次（事件写 `reveal:['keshang']`，或者冲突对生成待办时自动带出两边），他才进班子页的「见过面的」那一栏。一局下来你认识几个人，是你自己跑出来的。

年龄是硬的：58 岁以上的人在人事窗口里自动算「退二线候选」，45 岁以下的算「可以往上放」。

### 2. 冲突对

不是每两个人都有矛盾，写死 **10 对**，每对一个「热度」0~100：

| 对 | 因为什么 | 热度高了会怎样 |
|---|---|---|
| 市长 ↔ 书记 | 旧改、财政、谁说了算 | 常委会当场翻脸，主线 A 提前进第 4 幕 |
| 城关区书记 ↔ 高新区书记 | 抢一块地、抢招商指标 | 两边都往你这递材料告对方 |
| 青川县委书记 ↔ 青川县长 | 县长想把旧账翻出来 | 出匿名信 |
| 秘书长 ↔ 你 | 你越过他直接报书记 | 你的材料被压、你的行程被改 |
| 政法委书记 ↔ 纪委书记 | 一个想压，一个想查 | 主线 B 的材料到底给谁 |
| 前任秘书 ↔ 秘书长 | 那本账 | 主线 C 的来源 |
| 市委副书记 ↔ 市长 | 都想当市长 | 副书记在常委会上悄悄换边 |
| 综合科科长 ↔ 你 | 你提得太快 | 你的稿子被「不小心」漏字 |
| 市委办副主任 ↔ 你 | 争下一个副秘书长 | 你出差的时候他给书记递材料 |
| 白沙县委书记 ↔ 白沙常务副县长 | 年轻人 vs 老人 | 白沙的数字报两套 |

**热度只有两个来源**（v1.3 定）：**事件把它推上去，时间把它磨平**。没有自动上涨——每月固定往下掉半格左右，≥70 之后掉得慢（撕破脸了不容易好）。结果是：多数对子几年下来自己淡了，少数几对越走越远，而那几对是玩家自己的选择推出来的。唯一的例外是**市长 ↔ 书记**，这对是整局的底色，每年额外 +3，跟玩家做什么无关。

**秘书长那条**不靠事件：你这个月办掉五件以上，`p_msz_me` +4；三到四件，+2；月末安排选了「去秘书长办公室坐坐」，-10。他不舒服的不是你办错了什么，是你办得太多了。

≥70 的对子每月挑一个丢一件冲突待办出来，同一对子隔三个月才会再来；**≥90 触发摊牌链条**（三幕，2026-09-19 已做）：会上吵起来、纪要你写 → 两个人分别找你，一个上午来一个下午来，说的是同一件事的两个版本 → 组织部来问「你觉得谁更顾全大局」，这句话你答什么，答案会到书记桌上。三幕走完总有一个人要走，除非你说「两个人都还能用，是位置摆得不对」。摊牌链条是**现生成的**：模板 + 两个人名 + 这对子的由来，做出来的链条定义存进 `G.genArc`，所以存档读回来照样接着走。热度在班子页显示成一条线：不到 40 是虚的灰线，55 以上变实变粗，70 以上整行标红，名字加粗，后面跟一句「这个月该出事了」。玩家看不到数字。

**冲突待办用模板生成，不逐条手写**（`data/templates.js`）：四个模板——两边都递材料、来打听书记的口气、一件事卡在两人中间、会上当众下面子——用 `{A}{B}{WHY}` 代入，一件事就是模板 + 两个人名 + 这对子的由来。选项里 `fxA/fxB` 是对两边的好感，`heat` 是这对子的热度。

### 3. 排人（时间冲突）

书记每月只有 **4 个见面槽**（拍板项），求见的通常 6~7 个。这是一件固定的月初便签，叫「本月排人」：

```
┌──────────── 本月求见 ── 书记只有 4 个空 ────────────┐
│ ☐ 市长（例行碰头）             不排他会记着          │
│ ☐ 高新区书记（汇报招商）        排了城关区书记会不高兴  │
│ ☐ 城关区书记（旧改的事）        排了高新区书记会不高兴  │
│ ☐ 开发商乙（托秘书长约的）      排了干净 -3           │
│ ☐ 青川县长（说有情况要单独汇报） 排了热度 +15，不排匿名信 +1 │
│ ☐ 省委组织部处长（路过）        排了人脉 +5           │
│ ☐ 你爱人（想让你晚上回家吃饭）   （这个不占槽，占你半天）│
│                                                     │
│ 剩下的：☐ 让他们下月再来  ☐ 请秘书长安排  ☐ 我自己见一下（每人半天）│
└─────────────────────────────────────────────────────┘
```

排进去的人当月推进他的事件（好感 +，他带的事进队列）；没排的人三条路：下月再来（他的事顺延，好感 -3）、请秘书长安排（秘书长热度 -5，但他会记你一笔）、你自己见（花你半天，人脉 +1，他的事你先知道）。

书记性格决定他事后挑什么刺：稳健型不见外人（「外面的人少见。」），强势型不见告状的（「这种人不用见。」），精明型不见没用的（「这半小时值吗？」）。排进去一个他看不上的，信任 -2，月末那条批示就是上面那句。

**排人不顺延**：这个月的时间过去了就是过去了，没排的作废，按不办结算（信任 -4），下个月是新的一张条子。数据上写 `noRoll:1`。

秘书长每月也要塞一个人进来，你不给他，冲突对热度 +10。

### 4. 传话

书记跟人之间、人跟人之间的话经你嘴。「传话」便签一局 20 件左右，模板固定：

```
市长在电话里说：「你跟书记讲，旧改那块地的评估，我这边有不同看法。」
书记正在看文件。
  · 原话带到 · 半天             两边都知道你不加料
  · 说软一点：「市长那边想再议一议」· 半天   书记不急了，市长觉得你没带到
  · 加一句：「市长那边好像已经找过省里了」· 0   书记会问你哪听来的，热度 +15
  · 先不传，等书记问 · 0        两边都不知道，但市长下周会自己来
```

传话不扣多少天，扣的是关系：每个选项对两头 NPC 的好感、冲突对热度、你的口碑（「这个人嘴严不严」）各有一笔。加料的选项挂 `rule:'leak'`。

四个模板（`data/templates.js` 的 `TALK_TPL`）：某人让你带句话给书记、某人想让你在书记面前说句好话、书记让你去跟某人说一句不好听的、A 让你转告 B 一句硬话。两头从班子和区县里抽；`between` 那一类优先挑热度已经起来的对子——有矛盾才有话要带。每月四成概率出一件，第四个月以后才有。

写模板的时候注意：**每条路都要有人不舒服**。原话带到，两头都知道你不加料，但被说的那个人记住了你；把话说圆，他很感激，可事情拖到了下个月初，书记问起来你没法答；加一句料，书记抬头看了你两秒，问这话哪听来的。

### 5. 告状与匿名信

「有人找你」里单独分出两个子类：

**告状**：区长告区委书记、局长告分管副市长。便签，三个选项：呈书记（告状人好感 +，被告好感 -，热度 +）/ 转给纪委书记（线索不动，口碑「不好说话」）/ 压两天看看（可能被告先找上门）。

**匿名信**：寄到市委办、信封上写书记亲启，你先拆。卷宗规格：材料就是信本身（半天看）和你能核的一两样东西，认定是「真的 / 假的 / 半真半假」，拟办意见：原信呈上 / 附你的核实呈上（多 1 天）/ 转纪委 / 压下（rule:'conceal'）。信的内容跟冲突对热度挂钩，热度高的对子才出信。

一局匿名信 6~8 封，其中两封是冲着书记来的（主线 E）。

### 6. 谈话材料

书记要找某人谈话（提拔前、出事前、调走前），你准备材料。卷宗规格，材料是这个人的履历、考核、告状信、你自己见过他的记录（留存材料在这里派用场），认定是「能用 / 要动 / 要查」，拟办意见是你在材料首页写的那句话：「建议重用」「建议交流」「建议了解一下」，或者不写。

书记谈完之后批一句，这个人的命运（进池子的哪一档）就定了。你写的那句话，被谈话的人事后会知道——组织部长嘴不严。

### 7. 人事窗口（链条，每年一条）

已做：**第一年**四幕（摸底、名单、常委会、公示），**第二年**三幕（名单、常委会、公示期有人把名单发到了网上），**第三年**收口，只有一件便签「今年只动了两个人」——佟建民说今年谁也别惦记，名单上仍然没有你。第四年那一轮留到 S6 跟结局一起做。


每年年中开一次「干部调整」，4 幕，跨 3~4 个月：

| 幕 | 规格 | 内容 |
|---|---|---|
| 摸底 | 便签 | 组织部长来问书记「今年动几个」，书记让你先说说你听到的。三个选项：说实话 / 只说书记想听的 / 说你不清楚 |
| 名单 | 卷宗 | 组织部报上来 3~4 个位置，每个位置 2~3 个候选，材料是每人的考察材料（各半天）。认定是每个位置「谁更合适 / 谁有问题」。拟办：把谁的材料放上面、在谁名字旁边提醒一句、不插手 |
| 常委会 | 常委会卷宗 | 按人头表决，人事是副书记和组织部长的底线议题 |
| 公示 | 便签 | 公示期出不出事：热度 ≥70 的对子里有人上榜就出匿名信，池子里「干净有问题且你知道」的人上榜就出举报 |

**第一年那条已做**（2026-09-19）：摸底（书记让你先说说听到什么）→ 名单（卷宗，三个位置：城关区委书记、白沙县委书记、市委办副秘书长——副秘书长那一栏有施培南，没有你）→ 常委会 → 公示期第五天收到两封信。

调整完了，池子里的人真的动：区县页城关区那张卡片换成郑大林、下面那行变成「新上任，还在摸情况」，施培南的岗位变成副秘书长并标上调整月份。你在名单上给郑大林旁边提醒一句，他这一轮就不动——代价是市长记你一笔。你把自己的名字添进那一栏，组织部的人什么也没说，施培南也什么都没说。被你压了材料的人记你一辈子，被你放上去的人也不一定念你的好（看他的野心）。

书记的用人偏好按性格：稳健型用老人、强势型用自己人、精明型用有用的。你递的名单跟他偏好不合，信任 -3，合了 +3，你事先看不到偏好表，只能从前几次批示猜。

### 8. 秘书长

他是你直接上级，也是老书记留下的人。规则只有三条：

- 你这个月办掉五件以上，热度 +4；三到四件，+2。他不舒服的不是你办错了什么，是你办得太多了
- 热度 ≥50 起，每月随机一件你的待办「被压」：不是没了，是耗时多一天。那件事的小字里会多一句「这件在秘书长那儿转了一圈」
- 热度 ≥80 他去书记那坐一会儿，信任 -8，然后热度落回 50（他出了气）
- 月末安排选「去秘书长办公室坐坐」，热度 -10；排人的时候把剩下的交给他安排，再 -6，但他会记你一笔

反过来你也可以每月花半天「去秘书长那坐坐」（月末安排里多一个可选项），热度 -10，口碑 +1。

### 9. 你自己被抢时间

三种插队，都是从待办队列外面进来的：

- **书记临时叫你**：正在办的卷宗停下，扣 1 天，材料进度保留。一月最多一次
- **随行**：书记出差带你，3~5 天，期间队列冻结，回来所有「本月」的事剩余天数照扣。不去：信任 -5
- **家里**：爱人的事、父亲住院，跟随行撞在同一个月就是这个游戏最难的一个月

## 三之九、私事（已做，2026-09-19）

前面所有的诱惑都是工作上的：一个数、一个人情、书记面前一句话。但真正让人伸手的不是这些。是你妹妹被调去了档案室，是你岳父在走廊上等了三天床位，是你儿子要上的那所小学差一个名额，是你爱人问你这个月能不能早回来一次、而你一次也做不到。

这一节把「你自己的日子」做成系统。不加页签，全部还是待办，但它是这个游戏真正的发动机。

### 2. 私事不随机，是到期就来

时间表写死（`data/private.js`），玩家能预见，也躲不掉：

| 大约第几月 | 谁 | 什么事 |
|---|---|---|
| 8~10 | 妹妹 | 文旅局有个副科要竞聘 |
| 14~16 | 岳父 | 支架，心内科的床位要排三个月 |
| 22~24 | 表弟 | 想进事业单位，姑妈坐在你家客厅不走 |
| 28~32 | 儿子 | 上小学，划片那所连操场都没有 |
| 38~42 | 父亲 | 老家住不下去了，要转市一院 |
| 45~50 | 妹妹 | 提拔，或者调岗——看你前面得罪过谁 |

写死比随机难受得多：你从第一个月就知道第 30 个月有一所小学等着你。前面二十九个月的每一次伸手和每一次不伸手，都是在为那所小学铺垫。

### 3. 每件私事三条路，没有一条干净

- **走正路**：花你自己的东西。请假、排队、自己跑。代价落在工作上——书记问你这几天去哪了，事情没人办，信任掉。有的正路根本走不通：排队排到孩子开学。
- **求人**：欠一个人情。见下面的「欠账」。
- **伸手**：用职权换。干净掉、线索涨、暗账多一笔。

**没有「花钱解决」这种干净选项**。

**家底**：拍板做成一个看得见的数，但不上指标条——在「家里」页和档案页各一行，跟着一句话（「经不起一件大事」「这个月的水电还没交」）。开局 8 万，两个人的工资每月攒 0.25 万。六十个月自然攒下十五万，而私事的总开销在十九万上下：支架四万八、父亲转院三万、妹妹结婚十万、表弟一万。**永远差一点**，这是故意的。学区房要四十万，那条选项一局都亮不起来，除非你伸过手。

### 4. 欠账（新机制，跟暗账对称）

`G.owe = [{who, what, m, done}]`

你为私事求了谁，他名下就记一笔。三到六个月后，他来要账——一件他想办的事落在你桌上，而这件事你很难拒绝。

- **还了**：这笔勾掉。他以后还能帮你，而且更愿意帮
- **不还**：他把给你的东西收回去——孩子转学的手续卡住、岳父的床位没了、妹妹的岗位调整下来。而且从此是敌人

**欠账不上界面**（v1.3 拍板改）。哪个游戏会把「你欠了谁一笔」列成一栏给玩家看。它全程藏在背后，只在他来要账那天以一件待办的形式出现，文本里带一句「当初刘敏那个副科，是他一句话的事」，玩家自己想起来。结局页才摊开：欠过谁、还了没有。

这条推广到所有机制：**未来的负面影响一律不预告**。线索不给数字，干净藏起来，报复不点破，欠账不列表。玩家能看见的只有眼前这件事和它当场的样子。

### 5. 报复链：你拒绝了谁，谁就动你的人

每个常委、区县一把手、干部池里的人，都标一条**他能动到你家哪个人**：

| 谁 | 能动谁 |
|---|---|
| 城关区委书记 邵国栋 | 你妹妹（文旅局归他管） |
| 常务副市长 高振邦 | 岳父的床位（卫健口的钱他批） |

事件选项加 `grudge:'chengguan'`。仇积到阈值，出一件事：

```
文旅局的岗位调整下来了

刘敏从展陈科去了档案室。她在电话里说没事，就是清闲点，
以后周末能陪你妈打麻将了。

### 6. 爱人那条线

不写成无理取闹。她提的每一件都合理：孩子发烧要人接、她值夜班家里没人、她爸要住院、她想你一个月回来吃一次晚饭。你一件也办不到。

家庭压力到顶不是吵架，**是她不提了**。界面上就是家里那一栏的话变了：「她不问你几点回来了」。

### 7. 那位女同事

两个条件同时满足才出现：家庭压力 ≥10，且连着三个月选了周末加班。

拍板：**要写得真实，人就是有七情六欲**——但真实不等于写床。真实是那些能让人认出来的具体东西：她是宣传部借调来的，三十岁，离过婚，没孩子；材料明早要，你们留到十一点；她把一杯热水放在你桌角，说了句你最近太累了，就这一句，你抬头的时候她已经转身回座位了。\n\n越界那一条也这么写——不写过程，写那半年是什么样的，和你后来反复想起的那个细节：办公室那扇门到底关严了没有。

三个选项：

- **第二天把工位调开** —— 什么也没发生。半年后她调走了，你听说她男朋友也在机关。你心里空了一块
- **不越界，但接受这份关心** —— 灰区。家庭压力继续涨，办公室里开始有人拿这个说笑
- **越界** —— `rule:'lifestyle'`（纪律条目表加一条，严重度 4，红线）。好处是真的：这半年里有一个人是理解你的。代价三年后才来，落在巡视组那条线上，而且**把柄不在纪委手里，在某个同事手里**

**写作约束**（不变）

- 说人话，机关里的人说话是短句、留半句、打比方，不是排比
- 不写「首先其次」、不写结尾点题、不替玩家总结道理
- 选项说明（n）只写一句能看到的后果，不写数值
- 材料正文写成真的像那份文件的摘要，两三句，带一个可以核的数
- 批示不超过十个字
- 不出现真实地名、真实人物、真实案件，不影射具体在任官员
- 灰色选项必须能选，后果必须慢慢兑现，不当场惩罚
- **界面上不写说明书**。「左边点开一件」「这个月天数不够了」「还没有批示」「干部池在 S2 接进来」这类全部不要。空的地方就留一个破折号。要提示的，用画面提示：家里那一栏不写「家庭压力：中」，写「幼儿园的接送表上，这个月你的名字一次没出现」
- **月末安排、出身、结局这些地方也是事件文本**，按同样的标准写。「精力回得最多」不行，「两天电话没响，周一早上进办公室脑子是空的」可以

### 翻译腔自查（2026-09-19 审了一轮，这些是当场揪出来的毛病）

写完每一句，对着这张表过一遍：

| 别写 | 写成 | 为什么 |
|---|---|---|
| 代价是这四天你现在就先借了 | 这四天是从身上抠的 | 「代价是…」是英语 the cost is，中国人不这么说话 |
| 周一早上你是清醒的 | 周一早上进办公室，脑子是空的 | 「你是+形容词的」是 you are clear-headed 的直译 |
| 他谢得太用力了，用力到你心里发虚 | 他谢得太殷勤，殷勤得你心里发毛 | 「X 到 Y」（用力到／肯定到／快得让你…）是 so…that 的壳 |
| 这个结果让你松了口气，也让你想得更多 | 你松了口气，松完又开始想别的 | 「让你…也让你…」是 made you…and made you… |
| 这件事到此为止——你以为到此为止了 | 你以为这事就算过去了 | 英式反转，中文不这么使破折号 |
| 你不知道它什么时候会被人翻出来 | 哪天会被人翻出来，你不知道 | 中文口语不拿「它」指一份材料当主语 |
| 这个结果跟你没关系——除了{B}认为有 | 这事本来跟你没关系，可{B}不这么想 | except 从句直译 |
| 你拿到了三个电话号码，和一身酒味 | 换回来三个电话号码。回家的时候一身酒味 | 英语的 A and B 并列，中文要断开 |
| 你们两个都知道有这回事，也都知道对方知道 | 有没有这回事，两个人心里都有数 | 绕。中文把宾语提前更顺 |

**还有三条是用量问题，不是错**：

- **破折号全局不超过十处**。一两次是重音（「不是他要查——省里巡视组要来」），二十次就是翻译腔。审之前有 22 个，砍到 9 个
- **「这句话／这四个字＋一句评论」这个句式全局不超过六次**。审之前 18 次，成了口头禅。能换成「这一句」「这话」「当天下午就…」的都换掉
- **「你自己知道」「两头都」这类口头禅各不超过三次**。审之前「你自己知道」3 次、「两头都」8 次，现在是 0 和 3

审的办法：写个脚本把所有 `text` `nt` `n` `t` `passN` `failN` `after` 抽出来（一千多句），先按上面的表 grep 可疑模式，再统计重复的结尾和口头禅。光看不行，一定要统计——句式重复自己写的时候察觉不到。
