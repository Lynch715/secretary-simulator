# 大秘

市委书记的秘书，六十个月。单文件 HTML，双击就能玩，存档在浏览器本地。

江东省云州市，下辖三区三县。你二十九岁，市委办综合科副科长，被新到任的市委书记点名当秘书。
一个月二十个工作日，例行的事先占掉十到十四天，剩下的时间处理桌上四到六件待办。
天数总是不够，每个月你都得放下一两件。

书记的性格开局随机，你看不见，只能从他的批示里猜。
「干净」和「线索」这两个数你也看不见，只能从纪委的待办和别人看你的眼神里感觉。
灰色选项当月不惩罚，代价在三个月以后。没有补救，收了就是收了。

十个结局，跨局记在图鉴里。

## 改

`index.html` 是拼出来的成品，**不要手改**。源码在 `src/`：

```
src/css/main.css
src/js/*.js        引擎：队列、卷宗、常委会、纪律、链条、结局
src/data/*.js      内容：事件、主线、议题、干部池、模板、结局正文
build.py           把 src/ 拼成 index.html，零依赖
test/sim.js        无头跑局
```

改完跑：

```bash
python3 build.py        # 重新拼 index.html
node test/sim.js 200    # 四种打法各 200 局，看结局分布和报错
```

`test/sim.js` 会检查：能不能从第 1 月打到结局、十个结局判不判得出来、
五个页签渲不渲染得出来、存档能不能读回来。四种打法里「偶尔伸手」最接近真人。

加事件的时候注意：新的 `data/events_*.js` 要在 `data/zz_index.js` 里补一行，
**不要**把汇总逻辑写回任何 `events_*.js`（`var` 不提升赋值，会被静默丢掉）。
