# v2.6：议题口风、条件分支、任内回响与审计

本轮包含尚未上线的 v2.5 和本轮 v2.6。保留红头文件、纸底、原色板、字体、人物美术、四页签与卡片布局；仅对文字贴框、禁用按钮状态、长文字换行和窄屏按钮换行作修复。

## 剩余三项玩法

1. 打听针对最近将上会的议题留下口风，人物卡、来龙去脉和表决预览显示具体顾虑。针对已摸过口风的谈话对该议题给予有限修正，每人每议题只记一次，不因重复打听刷取。一般立场与本议题态度分开，预判不是保证票数。
2. 原有主线保留，住建原始补偿表、信访原件、土地档案、旧改督办记录会改变部分剧情的选项、取证路径和效果。分支在新月份开始时确定，存档后不重抽；旧档当前场景保留原选项编号。已离任人物的新场景改为交接与档案办理，避免继续当面约谈。
3. 结局沿用原正文样式，增加本局旧改补偿、青川文书、可靠干部办结记录及河流治理方案的后续。未办到的阶段不编造结果；补证清单不写成收件回执，复核不写成翻案，退休、调任与涉案分开。

## 已修复缺陷

| 范围 | 问题及修复 |
|---|---|
| 表决 | 动画期间可重复点击；现在立即禁用并缓存结果。保存/读档后沿用同一票数，散会与结算防重。 |
| 强行拍板 | 重复执行可能重复扣代价；增加状态校验。原来关系、材料等嵌套收益未减半，改为与文字一致。 |
| 预算 | 第一份预算让步后，即使输了也可能获得赢的收益；现在仅在通过时生效。 |
| 呈批 | 陈旧或非法目标、余额不足仍可能提交；提交前统一校验，禁止同一候选人同时报两个岗位。 |
| 人事会 | 重复执行、同人在同场会被连续安排；结果缓存并阻止重复任职。 |
| 部门 | 增加实际掌握部门、冷却、目标、党校状态校验；已待查的同一人不重复立案。 |
| 调查目标 | 直接按隐藏污点筛选，导致名单泄露真实属性，干净分支不可达；改按已知情况筛选。 |
| 干净分支 | 审计及调取记录的干净结果把数组当字符串处理，可能报错；统一先选取文字，并记下查清结果。 |
| 立案结算 | 实际按调任处理；改为审查调查，月份保持初核一月、立案侦查两月，呈批记录补真实结果。 |
| 呈批文字 | 部门行动被拒仍按批准色态显示、结果空白；现明确显示未获批准，兼容旧记录。 |
| 青川离任 | 吕宏泉若已调到别处，被处理后仍占岗；统一清理真实岗位。旧档遗留的这类错占，仅修正错误岗位引用，不追扣资源。 |
| 副市长路线 | 选择推荐卢志高仍被另一条表决先结算；修正路径。晋升按实际岗位交接，不误清住建接任者；原人已离任时不复活。 |
| 人物/时间 | 晚期仍让退休干部当面来汇报、五年结局写这三年、调任退休都称出事；修正叙事与标签。 |
| 存档 | 无效导入可污染当前状态、空封面可能覆盖有效存档；导入先验证再替换，空状态不写存档。 |
| 文字/按钮/边框 | 待办文字贴框、禁用按钮不明显、窄屏长说明或按钮可能挤压；保留原设计作局部修复。 |
