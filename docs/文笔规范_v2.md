> 这份跟规范 v2.0 配套，所有事件正文、对话、选项、批示、战报、结局都按它写。写之前读一遍，写完按第五节自查。

## 一、这是一本官场小说，不是一张表

玩家每个月看到的东西，要像翻开一本书的某一页：有人，有地方，有一句话没说完。数值在界面上，正文里一个数都不许出现。

语感往这几本书靠：王跃文《国画》《梅次故事》、阎真《沧浪之水》、黄晓阳《二号首长》、王晓方《驻京办主任》。只学语感，一个句子都不抄。

它们的共同点：

- **白描**。不形容人，写他做了什么。高振邦是什么样的人，看他给你倒茶放多少茶叶就知道了
- **话说半句**。领导不把话说透，说透了就不是领导了。意思在停顿里、在称呼里、在他看你那一眼里
- **小事写大**。一把伞、一个座次、谁先伸的手、茶杯放在哪边，这些就是权力
- **不评判**。作者不站出来说谁好谁坏，玩家自己看

## 二、怎么写

### 1. 动作代替形容

| 别写 | 写成 |
|---|---|
| 陈立群是个老谋深算的人 | 陈立群先伸的手。握完，他很自然地往旁边让了半步，让周维安走在前面，自己落后一个肩膀 |
| 高振邦很紧张 | 高振邦把那份文件又翻回第一页，看了一遍抬头 |
| 气氛很尴尬 | 没人接话。方静仪低头拧开了保温杯 |
| 他很生气 | 他把笔帽扣上了 |

### 2. 对话

- 说话就是说话，少用「他说道」「他笑着说」。谁说的，靠前面那个动作带出来：
  > 周维安把车窗摇下一条缝。「桥墩上有字。」
- 一段对话里「说」字最多出现一次
- 领导说短句。越大的官话越短，你（秘书）的话最短
- 不许让人物把自己的动机讲出来。高振邦不会说「我想接市长」，他会说「罗书记是省里来的，云州的事他不一定熟」
- 称呼就是关系：当面「周书记」，背后「老周」，市长那边的人背后叫他「那位」；领导当面叫你「小刘」，背后叫「刘秘书」，再后来叫「刘主任」。称呼一变，关系就变了，要当成剧情写
- 用「」，不用 ""

### 2.5 对书记的称呼（2026-09-27 他提的）

书记是一把手。当着书记、当着秘书，所有人一律叫「周书记」「书记」，市长也一样。不许「他」「老周」一笔带过，不许拍书记的胳膊、替书记下结论。不满只能藏在程序里、客气话里、拖延里：

> ✗ 「他刚来，好多情况不了解，不怪他。」
> ✓ 「周书记刚到云州，情况还要慢慢熟悉。我们做具体工作的，多担待一些。」

写完用脚本把所有台词里提到书记的地方扫一遍。

### 2.6 人物简介写成履历

卡片上那一行只写客观的东西：年龄、出身、在云州几年、上一个职务、分管什么。不写性格、不写评价。一个人什么样，让玩家从戏里看出来。

> ✗ 问的都是会不会上网
> ✓ 51 岁。省报记者出身，任宣传部长四年，分管宣传、网信、文化

### 3. 场景一笔，细节一处

场景不要铺。一句话交代在哪儿，然后给一个具体的东西：

> 高振邦的办公室在市政府五楼，朝南，一整面墙的书，大半没拆塑封。

一件事一个细节就够，两个就多了。

### 4. 节奏

- 段落短。手机上一段不超过四行，一行一个动作也可以
- 事件正文 150~400 字。交锋的「决」那一幕可以到 600
- 结尾停在一个动作或一句话上，不写感想。下面这种结尾全部不要：「你意识到，这场较量才刚刚开始」「你心里明白，事情没有那么简单」

### 5. 选项也是小说

选项是「你」接下来说的话或做的事，写成能直接接在正文后面的样子：

| 别写 | 写成 |
|---|---|
| 支持高振邦的预算方案 | 「高市长考虑得周全，我回去跟书记汇报。」 |
| 向书记汇报此事 | 回去把他那句「方部长」原样说给书记听 |
| 拒绝 | 茶没喝，起身说还有个会 |

办完之后那一段（结果）同样按小说写，一到三句。

### 6. 批示和战报

- 批示是周维安的笔迹：十个字以内，可以只有一个「阅」，可以是一个问号
- 战报是你听到的、看到的，不是系统通知：
  > ✗ 市长拉拢了宋自强，宋自强倾向下降
  > ✓ 传达室老张说，上周四晚上陈市长的车在纪委楼下停了一个多钟头

## 三、黑名单

### 网文腔、AI 腔，一个都不许出现

嘴角勾起一抹 / 眼中闪过一丝 / 心中五味杂陈 / 空气仿佛凝固了 / 不禁 / 缓缓说道 / 意味深长地 / 深邃的目光 / 淡淡地 / 一股莫名的 / 仿佛在诉说着 / 心头一紧 / 不由得 / 目光如炬 / 气场 / 微微一笑（全局限三次）/ 沉默了片刻（全局限三次）/ 不动声色（全局限三次）

### 机翻腔（沿用 v1.3 那张表）

| 别写 | 写成 |
|---|---|
| 代价是这四天你现在就先借了 | 这四天是从身上抠的 |
| 周一早上你是清醒的 | 周一早上进办公室，脑子是空的 |
| 他谢得太用力了，用力到你心里发虚 | 他谢得太殷勤，殷勤得你心里发毛 |
| 这个结果让你松了口气，也让你想得更多 | 你松了口气，松完又开始想别的 |
| 你不知道它什么时候会被人翻出来 | 哪天会被人翻出来，你不知道 |
| 你拿到了三个电话号码，和一身酒味 | 换回来三个电话号码。回家的时候一身酒味 |

再加四条：

- 「被」字句能换就换：「他被调走了」→「他调走了」「上面把他调走了」
- 「一个」「一种」砍掉一半：「一种说不出的感觉」→ 删掉整句
- 「进行」「作出」「加以」这类公文动词只许出现在公文里（红头文件、会议纪要），叙述里不用
- 破折号全局不超过十处

### 四字词

成语一段最多一个。四字短语不许连着用，「风云变幻，暗流涌动」这种直接删。

## 四、人物声音档案

写谁的话之前先看他这一行。写完遮住名字，读得出是谁说的才算过。

| 人 | 说话 | 口头上的东西 | 绝不会 |
|---|---|---|---|
| **周维安** 书记 | 极短，常用反问。问你问题的时候，其实已经知道答案 | 「你说呢」「这个数谁给的」；叫人名不叫职务，表示亲近也表示不客气 | 解释自己为什么这么做；骂人 |
| **陈立群** 市长 | 慢，客气，爱讲云州的旧事。每句话都给人留台阶，台阶底下是坑 | 「我在城关当区长那几年」「周书记是外面来的，看问题比我们清楚」 | 当面说一个「不」字 |
| **高振邦** 常务 | 算账，数字张口就来，喜欢拿别人挡在前面 | 「盘子就这么大」「我是替某某着急」 | 提自己想要什么 |
| **罗明川** 副书记 | 什么都说好，什么都不答应 | 「再研究研究」「两位领导的意思我都理解」 | 在会前表态 |
| **宋自强** 纪委 | 话最少，问的全是时间地点 | 「哪天」「几个人」「东西在哪」 | 寒暄；收任何东西 |
| **佟建民** 组织部 | 老派，讲程序，说话前先喝口茶 | 「按程序」「这个同志嘛」 | 当着第三个人谈人事 |
| **方静仪** 宣传 | 客气里带着怕，问的都是「会不会上网」 | 「这个要是传出去」 | 替谁出头 |
| **邱仲华** 秘书长 | 长辈口吻，叫你「小刘」叫得最亲，也最冷 | 「我干秘书那会儿」「你还年轻」 | 直接指点你该怎么做 |
| **韩树声** 政法 | 粗，爱打比方，话里带刀 | 「这事就跟破案一样」 | 在纪委面前多说一句 |
| **你** | 话最少。回领导话一般不超过十个字 | 「好」「我去办」「我回去查」 | 给领导出主意时用「我觉得」开头 |

## 五、写完自查

1. 正文里有没有数字、有没有系统口吻
2. 黑名单那几十个词 grep 一遍
3. 遮住说话人，能不能分出是谁
4. 每段是不是停在一个动作或一句话上
5. 一段对话里「说」有没有超过一次
6. 有没有人把自己的动机讲出来了
7. 选项能不能直接接在正文后面读

黑名单用脚本扫（沿用 v1 那套抽 text/n/t 的脚本），光靠看不行。

## 六、样章

两段，定调用。以后写的都照这个水准。

### 样章一：到任（第 1 个月开场）

周维安到云州那天下着小雨。

车从高速口下来，他一路没说话，看着窗外。过城关区那座老桥的时候，他忽然问你：「这桥哪年修的？」

你愣了一下。「八几年，具体的我回去查。」

「不用查。」他把车窗摇下一条缝，「桥墩上有字。」

你扭头去看，车已经开过去了。

市委大院门口站了一排人。陈立群站在最前面，伞没打，头发上挂着一层细水珠。他先伸的手。

「周书记，一路辛苦。云州这个天，算是给你接风了。」

「陈市长客气。」周维安握着他的手没松，「雨不大，正好醒醒脑子。」

两个人都笑了。后面那一排人也跟着笑，笑声停得很齐。

晚上九点，你把第二天的日程送到他房间。他在看云州去年的财政决算，眼镜推在额头上。

「小刘。」他没抬头，「今天门口那一排，你认得几个？」

「都认得。」

「那你说说，谁的伞是自己打的。」

你想了一会儿。高振邦的伞是秘书举着的。韩树声没带伞，站在陈立群身后半步，陪着一起淋。吴敬之的伞最大，一直往书记这边偏。

你说了。他点点头，把决算翻过一页。

「明天开始，你替我记个本子。」

### 样章二：第一份预算 · 起（第 2 个月）

高振邦的办公室在市政府五楼，朝南，一整面墙的书，大半没拆塑封。

他亲手给你泡茶，茶叶放了小半杯。

「周书记那三件事，我都支持。」他把杯子推过来，「旧改、招商、化工园，哪一件不是云州该办的？」

「那预算里……」

「预算是预算。」他坐回去，「盘子就这么大。小刘，你是笔杆子出身，你算算。旧改要四个亿，今年挤出一个半，已经是把二中的扩建往后推了。你让我怎么跟方部长交代？」

说到「方部长」三个字，他看着你。

你听明白了。二中是方静仪丈夫管的那一片。旧改的钱多一分，方静仪那边就少一分，到时候在常委会上替二中说话的，不会是高振邦。

他站起来送你，手搭在你肩上，一直送到电梯口。

「替我跟周书记带个好。」电梯门关上之前，他说，「他刚来，好多情况不了解，不怪他。」

**选项**

- 「高市长考虑得周全，我回去跟书记汇报。」
- 回去把「方部长」那句原样说给书记听
- 先去宣传部坐一坐，看方静仪知不知道这件事
- 从财政局要一份二中扩建的原始预算（要有人在财政局）

**办完之后**（选第三条的样子）

方静仪不知道。她听完，拧开保温杯喝了一口，半天没说话。

「二中那边，我一直以为是住建卡着。」她把杯子放下，「谢谢你啊，小刘。」

那一声「小刘」，她叫得比平时慢。
