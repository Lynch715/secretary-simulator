## 〇、为什么 v1 不好玩，v2 改什么

v1 玩家一直在**处理事**：待办排成队，一件件点开、看材料、选拟办意见、看天数够不够。对手是藏着的，赢了也看不见什么变化。拔钉子那一节想补这个，但它是挂在待办队列上的一条支线，底盘还是「点点点」。

v2 把底盘换成一张**棋盘**：

- **票看得见**。常委会十一个人，每个人站哪边，一排格子摆在最上面，一局打下来看着它从红慢慢变成墨色
- **位子看得见**。市直、区县、两办、政法那二十几个要害岗位，一张组织图，每个格子里坐着谁、是谁的人
- **对手看得见**。市长每个月也在下棋：拉人、安插人、挖你的底。他动了什么，一部分你当月就知道，一部分你要有人在那边才知道
- **赢是具体的**。市长怎么倒的，你亲手一步步铺出来的

待办队列、每月天数、卷宗读材料、家里三十件日常，这些 v1 的主体全部退到后面或者砍掉（见第十节）。

## 一、局面

**云州**，地级市，三区三县，沿用 v1 的地图和人。

**书记 周维安**，外省空降，第 1 个月到任。班子里没有一个自己人，只从高新区带来了一个吴敬之。性格照旧随机三选一（稳健 / 强势 / 精明），决定他批不批你的拟办、肯不肯冒险、会不会弃子。

**市长 陈立群**，在云州干了十一年，从城关区长做上来。常务副市长、政法委书记、城关区委书记、住建财政两个局都是他的人。他不是坏人脸谱，他有他的道理：云州这些年的路是他修的，外地来一个书记要推倒重来，他不认。

**你**，书记的秘书，刘＿（沿用开局起名）。书记的很多事自己不能出面，你去。你去了，账就记在你头上。

**时间**：一月一回合，**36 个月到换届**。换届那一场是最后一仗：新一届常委会名单谁定、市长还在不在上面。

## 三、位子：二十四个格子

一张组织图，每个格子一张头像。格子分四组，每个位子自带一样**用处**，你的人坐上去用处归书记，市长的人坐着用处归市长：

| 组 | 位子 | 用处 |
|---|---|---|
| **两办** | 市委办常务副主任 | 你的后方，市委这边文件不漏 |
| | 市府办主任 | 能看见市长那边的文件流转：市长下个月要上什么议题，提前一个月知道 |
| | 市长秘书 | 最难安插的位子。坐上去，市长每个月的动作你都看得见 |
| **政法** | 公安局长 | 能查案、能保人；市长的人坐着，你家里人的事会被翻 |
| | 检察长 | 把柄能「坐实」，落马那条路少不了他 |
| | 纪委副书记（监委副主任） | 宋自强办案的手，案子快一倍 |
| **市直** | 财政局长 | 每年的预算盘子：你手里能许出去的钱多少看他 |
| | 发改委主任 | 项目：给常委许项目要他点头 |
| | 住建局长 | 旧改；工程里的账 |
| | 审计局长 | 查账，挖把柄最快的一条路 |
| | 自然资源局长 | 土地；高新区扩区要他 |
| | 教育局长、卫健委主任 | 方静仪丈夫、高振邦都盯着；老百姓那头的事 |
| | 信访局长 | 举报信先到谁手上 |
| | 国资委主任 | 港口那几家国企 |
| **区县** | 六个区县的书记和区县长（12 格） | 区县书记的人跟谁，那个区县的事就向着谁；高新、城关、青川三个地方跟三件大事绑着 |

加起来 26 格，常委兼的不算。开局书记这边只有 3 格（高新区两个、市委办常务副主任空着），市长那边 11 格，其余是中立或老书记留下的人。

### 怎么把人放上去

1. **有空缺**。空缺来路：到龄退休（写死时间表）、有人被拿下、有人被调走、你撬出来的（把一个人平调走，他的位子就空了）
2. **提名**。组织部长提，或者书记直接点名。佟建民不配合的时候，书记点名要花威信
3. **过常委会**。干部调整也要表决，这是票和位子扣在一起的地方：没有票放不上人，放不上人换不来票
4. **级别要够**。科级不能一步当局长。破格提拔花威信，而且被提的人从此是众矢之的

每个季度第二个月有一次干部调整会，平时空出来的位子攒到那时候一起上。急的可以单独上会，书记花威信。

### 坐上去的人也会变

每个人对提拔他的人有一个**念恩**，逐月往下掉；市长会去拉他。念恩掉到底的人会被策反，而且不告诉你。你要时不时去坐一坐（行动「回访」），或者给他下一步的指望。

## 四、苗子

书记这边没人，人要自己找。

**干部池 40 人**：v1 的 14 个手写干部保留，再加 26 个（手写 10 个带故事的，16 个按模板生成的中层）。每人：

| 看得见 | 要去查才知道 |
|---|---|
| 姓名、年龄、现职、级别、出身（选调生 / 本土 / 部队转业 / 省里下派） | 真实倾向：他是不是市长的人 |
| 能力一档（平平 / 能干 / 一把好手） | 污点：有没有经济问题、作风问题 |
| 一句别人对他的评价 | 野心：给他一个位子他满不满足 |

**找苗子的路**：

- **下基层**（你的行动）：去某个区县或某个局跑一趟，碰见一到两个人。碰见谁看你去哪儿
- **常委推荐**：佟建民、方静仪、纪守望的诉求里有「把我的人放上去」，这些人也进池子，放上去换票，但他们首先是别人的人
- **自己找上门**：有人托关系来见你。**市长的暗桩最常从这条路来**，能力一般是「能干」，评价很好，太好了

**考察**（你的行动）：查一个人的底，一次翻开一样暗属性。查三次翻全。没查就提的人，提上去以后才露底：可能是个好官，可能三个月后就把你们的名单送到了市长桌上。

v1.5 的暗桩、红鲱鱼、露马脚那套全部挪到这里：市长每局随机埋 2 个暗桩在苗子里，另有 3 个看起来可疑、查下去是清白的。

## 五、每个月

```
战报：上个月市长那边露出来的动作；这个月的空缺、到龄、事件
  ↓
你的三件事（精力好的月份四件）
  ↓
给书记的拟办（最多两条）→ 书记批不批，批示照旧按性格
  ↓
交锋（有的话）：这一回合的出牌
  ↓
常委会（有的话）：票面、会前最后一轮、表决
  ↓
月末：市长行动（背后）、念恩和倾向漂移、反扑判定
```

一个月一屏打完，不再排天数。

### 你的行动（每月 3 次）

| 行动 | 对谁 | 当场看得见的 |
|---|---|---|
| **摸底** | 常委或干部 | 翻开他一条诉求或底线 |
| **做工作** | 常委 | 把书记的一个许诺带到（许诺要先有拟办批下来），倾向涨一档左右 |
| **递话** | 两个人之间 | 传书记的意思，或者把 A 的话带给 B。可以加料（灰） |
| **下基层** | 某个区县或局 | 碰见一两个苗子；那个地方的一件事 |
| **考察** | 苗子 | 翻开他一样暗属性 |
| **回访** | 自己人 | 念恩补满；他告诉你一件他那边的事 |
| **挖** | 市长那边的某个人 | 看你在哪有人：审计有人查账，公安有人查案，信访有人翻举报信。一个都没有就只能自己去打听，慢而且容易被发现 |
| **护** | 自己 / 家里 | 反扑压下去一点，把身边的窟窿堵上 |

### 给书记的拟办（每月 2 条）

你写，他批。拟办的内容：

- **提名**：某人到某位子
- **许诺**：给某常委一样他要的东西（项目、预算、他的人的位子、将来的市长位子）。许了要兑现，兑现不了那人翻脸，而且记一辈子
- **上会**：把某个议题提上常委会
- **去省里**：书记去省委汇报一次，风向和省里的态度动一动
- **动手**：把手里的把柄用出去（见第七节）
- **硬拍板**

书记批不批看三样：他对你的信任、这件事要花多少威信、合不合他的性格。强势型什么都敢批，精明型会先问「那边会怎么接」，稳健型一半不批。不批的时候批示写着为什么，写成人话。

**资源**只有三样，都在顶上：

| 资源 | 是谁的 | 怎么来怎么走 |
|---|---|---|
| **威信** | 书记的 | 交锋赢了、常委会过了涨；硬拍板、破格、许诺没兑现掉 |
| **盘子** | 书记能动的钱和项目 | 每年初按财政局长是谁的人发：自己人 6 份，中立 4 份，市长的人 2 份。许诺一个项目花一份 |
| **信任** | 书记对你 | 你办成的事涨；你的反扑落到书记身上就掉。掉到底，你被换 |

## 六、交锋：八场仗

书记和市长的正面冲突写死 8 场，按时间表来，中间夹着市长主动挑起的突袭。每场三段，拉两到四个月：

| # | 仗 | 大约 | 赌注 | 怎么决 |
|---|---|---|---|---|
| 1 | 第一份预算 | 2~4 月 | 书记三件事的钱在不在盘子里 | 常委会 |
| 2 | 公安局长人选 | 5~8 月 | 公安这把刀在谁手里 | 常委会 + 韩树声 |
| 3 | 城关旧改 | 7~12 月 | 城关区的地；邵国栋和两家开发商 | 常委会，市长当场翻脸 |
| 4 | 青川化工园的旧账 | 10~15 月 | 翻不翻；翻了韩树声和马汉江一起摇 | 纪委 + 省里 |
| 5 | 副市长空缺 | 14~18 月 | 两边各推一人；罗明川第一次亮底牌 | 常委会 |
| 6 | 省里年度考核 | 每年 12 月 | 谁的账算在谁头上 | 省里排名，不投票 |
| 7 | 港口国企改制 | 20~26 月 | 崔延平那本账、邱仲华那一票 | 常委会 |
| 8 | 换届 | 33~36 月 | 下一届常委会名单，市长在不在上面 | 省委组织部考察 + 常委会推荐 |

每场的三段：

- **起**：事情摆上来，两边各自的立场，谁站哪边一目了然
- **争**：两三个月，你用行动和拟办去拉人、造势、挖对方的软肋；市长同时在做一样的事。这几个月战报上天天有东西
- **决**：表决或者省里裁，当场出结果

赢一场：威信涨，市长那边掉一两票的倾向，常常还空出一个位子。输一场反过来，而且市长会追着打。

**市长的突袭**：他每季度大约主动出一件事，不在时间表上：一封告书记的信到了省里、城关区突然出一场群体上访、你安插的人被查出问题。有市府办主任或市长秘书在手的，提前一个月知道。

## 七、把柄和刀

市长派里每个人都有一个把柄，写死，大半沿用 v1.5 的钉子表（邵国栋的十一页、青川的事故报告、卢志高的工程台账、高振邦的专项、阮学文的三道弯……）。市长本人的把柄分三块，要拼齐。

**拿把柄**：「挖」这个行动。在对应的位子上有自己人，挖得快、挖得实；没人就只能打听，拿到的是传言，用不了，还可能打草惊蛇。

**把柄三档**：传言 / 有东西 / 坐实（坐实要检察长或纪委副书记是自己人）。

**用法**：

| 用法 | 要几档 | 结果 |
|---|---|---|
| **捏着** | 有东西 | 他那一票在底线以外的事上不再跟你硬顶 |
| **逼他换边** | 有东西 | 私下摊开。他换过来，但他恨你；以后有机会就咬回来 |
| **交纪委** | 坐实 | 宋自强接了，几个月后人倒。空出位子，宋自强倾向涨 |
| **调走** | 有东西 | 书记跟组织部一说，平调走人。温和，不树死敌 |
| **寄出去**（灰） | 传言就行 | 匿名信、透给省报。当月见效，但他知道是谁 |

一次只动一个人，动完隔两个月。动得越快，反扑越狠。

## 八、马前卒

脏活是你去干的。市长恨的不只是书记，更恨**动手的那个人**。

**反扑**（背后的数，不上界面）：你每做一次挖、寄、逼、加料，它就涨。过线就出事，事情照 v1.5 的四档，落在你身上和你家里：

- 市长办公室来要你的行程
- 一封告你的信到了纪委，信里写的是你真做过的事
- 你妹妹的岗位、岳父的床位、孩子的学校被动了
- 有人在楼下等你

v1 的家人（周雪、刘敏、岳父、儿子）留着，但不再每月出事。他们只在两种时候出现：市长拿他们开刀，或者你为了护他们要做一个选择。

**弃子**：这是马前卒的命。书记被省里约谈、或者一场交锋输得太难看、而你的反扑又已经很高的时候，书记会考虑把你推出去：「你去党校学习三个月」。这三个月你离开棋盘，你放上去的人没人回访。能不能躲掉，看你手里有没有让书记舍不得的东西：信任够高、手里还攥着没交出去的把柄、有常委替你说话。精明型最容易弃子，强势型最不容易。

**省里各打五十大板**：两边斗得太响（内斗热度过线，交锋输赢不论），省里会把书记和市长一起调走。这是双输结局，提醒玩家：快刀不一定好，动静太大也是输。

## 九、结局

**势**：顶上一根拔河条，书记在左市长在右。它由票面、位子、交锋输赢算出来，是玩家看局势的总表。

**市长的四种下场**（赢）：

| 下场 | 怎么走到这 |
|---|---|
| **落马** | 市长三块把柄拼齐并坐实，交纪委，宋自强是这边的人，省纪委接手 |
| **调走** | 常委会连续三次表决书记赢，势过线，书记去省里说一次话；市长调省政协或者平调外地 |
| **换届出局** | 撑到换届，新名单上没有他，去人大或政协 |
| **他自己走了** | 落马路线的一个走向，不是玩家能选的目标：把柄拼齐、留置之前、他在这一局里被逼得太紧（背后有一个数：你们一年里拿掉他身边几个人、有没有给他留一条路）。写法克制，一段话，从你的角度写那天早上的消息是怎么传过来的，不渲染，不写过程 |

**输**：

| 下场 | |
|---|---|
| **书记被挤走** | 势掉到底，或者省里认定他「驾驭不了班子」，调离；你跟着坐冷板凳 |
| **书记落马** | 市长那边挖到了书记的东西（v1 的书记家里人那条线，挪过来做市长手里的牌） |
| **你被弃** | 弃子没躲掉，而且之后书记再没把你叫回来 |
| **你自己出事** | 反扑到头 |
| **一起调走** | 省里各打五十大板 |

**你自己**：赢了之后看书记的去向和你手里的东西，接 v1 的几个去向（随书记高升 / 外放区县 / 调省委办 / 留任）。结局页照旧摊开背后的账：你伸过几次手、你安插的人后来怎么样、你拿掉的人后来怎么样。
